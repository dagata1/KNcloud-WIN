# KNcloud-WIN

基于 Wails + React + Xray-core 的 Windows 11 原生代理客户端（Fluent / Mica 视觉风格）。

## 功能

- **真实代理内核**：内置 Xray-core（源码级嵌入编译，无需外部内核文件），支持 VLESS / VMess / Trojan / Shadowsocks 节点，本地提供 SOCKS5 与 HTTP 代理入站
- **TUN 全局模式**：基于 wintun + gVisor 用户态协议栈的进程内转发（`tapstack.go`），复刻 SSTap 的常驻虚拟网卡 + 静态分流路由方案。虚拟网卡常驻复用，开关只动路由表与转发协程，秒级生效（需管理员权限）
- **订阅管理**：真实拉取订阅链接（自动识别 Base64 / 明文分享链接列表），解析 vmess:// vless:// trojan:// ss:// hysteria2:// 链接，自动过滤机场"流量信息/套餐到期"伪节点；支持订阅更新与删除
- **账户体系**：支持 KNcloud 官网（V2Board 面板）密码登录与**网页授权登录**（浏览器回调），自动拉取订阅地址、套餐流量与到期时间
- **分享链接导入**：服务器页「导入分享链接」弹窗，支持每行一条批量导入、直接粘贴 Base64 订阅内容，或从剪贴板一键导入
- **节点管理**：多选（Ctrl+A 全选 / Ctrl+点击 / Shift+范围选择）、批量真连接测速、批量删除
- **节点测速**：真连接延迟测速（经节点完整代理链路请求测速 URL，口径与 v2rayN 一致）
- **路由分流**：绕过大陆（geoip:cn / geosite:cn 直连）、全局代理、全局直连、仅代理国内，以及 SSTap `.rules` 规则文件；内置广告拦截规则（geosite:category-ads-all → 阻断）
- **真实流量统计**：从内核 stats 计数器每秒采样，实时速率与累计流量
- **系统代理**：一键接管/还原 Windows 系统代理；应用退出时自动还原，不留死代理
- **系统托盘**：常驻托盘，支持切换模式 / 切换节点 / 退出；可配置关闭窗口时最小化到托盘
- **持久化**：节点、订阅、设置、累计流量保存至 `%APPDATA%\KNcloud\config.json`，重启自动恢复
- **端口冲突检测**：内核启动前预检端口占用并给出中文提示（可在首选项中修改端口）

## 构建

```bash
wails build        # 产物位于 build/bin/KNcloud-WIN.exe
```

开发模式：`wails dev`（前端热更新，Go 方法可在 http://localhost:34115 调试）。

### 测试

```bash
go vet -unsafeptr=false ./...
go test -short ./...       # -short 跳过会动系统剪贴板 / 拉起浏览器的用例
go test ./...              # 本机完整跑（会临时改写剪贴板、打开浏览器）
```

CI（`.github/workflows/build.yml`）在构建前会执行上面的 vet 与 `-short` 测试。

## 说明

- **TUN 模式需要以管理员身份运行**（要写系统路由表、创建虚拟网卡）
- Hysteria2 节点可导入展示，但 Xray 内核不支持其代理转发，启动该类节点会给出明确错误
- 默认端口 SOCKS5 `10808` / HTTP `10809`，与其他代理软件冲突时请在「首选项设置」中修改
- 「启动时自动连接」默认关闭：程序启动只起界面，代理由你手动开启。需要开机即接管系统代理可在首选项中打开（从旧版本升级的用户会保留原有的自动连接行为）
- 「允许局域网连接」开启后，入站会监听 `0.0.0.0` 且**不做任何认证**，同一网络内的设备都能使用该代理 —— 请勿在公共 WiFi 下开启
- 当前仅内置 Xray-core 一种内核，首选项中的「底层 Core 类型」为只读展示
